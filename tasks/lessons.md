# Lessons

- 2026-09-08 — Brand copy must be one constant. The name "הוואו היומי" was hard-coded in ~10 files (engine, emails, routes, tests) and renaming needed a sweep. Rule: user-facing brand strings come from `APP.name` (config) or i18n; never inline them. Also: zsh does not word-split unquoted `$var` in `for f in $files` — use an explicit list or `${=files}`.
- 2026-09-08 — The user's instinct for the landing was "community, not commercial": no screenshots, no steps, no prices, one CTA. Default to the quietest version of a page and let the manifesto/FAQ carry the detail.
- 2026-09-12 — A silent failure is worse than a loud one. The nightly build for #5 was blocked by an egress 403, nothing downstream noticed, and the first person to find out was a kid with no lesson in their inbox. `send-daily` had been returning `no_edition_today` to a cron nobody reads. It now records a `no-edition` job run and mails the editor once for that date. Rule: every branch where a scheduled job decides to do nothing must leave a trace a human will see.
- 2026-09-12 — The prompts that actually run lived only in the routine editors. Overwriting one to pass a fire payload destroyed it, and three release attempts failed with no admin URL and no bearer key while the lesson sat staged. `kit/prompts/` held templates, not the running copy. `npm run prompts` now renders the running copy from the repo (secret excluded). Rule: if production behaviour lives in a text box, the repo must be able to regenerate it.
- 2026-09-12 — Re-dating an edition is not just a metadata change. `late` is `today > edition.date` and the streak walks released days completed on time, so releasing a back-dated edition inserts a missed day and resets every kid's streak. The page also bakes its own date into the hero, which the app does not override — both editions needed the label patched by hand after the re-date.
